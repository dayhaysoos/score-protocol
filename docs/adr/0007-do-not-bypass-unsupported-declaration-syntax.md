# Do not bypass unsupported declaration syntax

Declaration syntax is fail-closed only when it belongs to an approved Declaration Closure: preparation reports unsupported source forms before review or paid execution, and candidate-only unsupported forms fail the Candidate Declaration Gate. SCORE provides no waiver or unverified fallback, because selectively disabling the gate where its interpretation is uncertain would invalidate the guarantee; unrelated repository syntax remains outside the gate.
